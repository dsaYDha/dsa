# 피아식별

전쟁 중인 도심 시가지를 배경으로 한 브라우저 1인칭 시가전 FPS.
양측 군복은 거의 같고, 몸에 붙인 **빨간 표식(완장·헬멧 띠)** 이 적, **파란 표식** 이 아군, 표식 없는 사복이 민간인이다.
언제 어디서 튀어나올지 모르는 적을 최대한 많이 사살하되, **쏘기 전에 확인** 해야 하는 생존 모드.
게다가 적은 가끔 **아군·민간인으로 위장** 해 섞여 든다 — 파란 표식이라고, 사복이라고 항상 안전한 건 아니다.

> 현재 **3단계(위장 적, 시각 단서 관찰)** 까지 구현. 전체 계획과 구조는 [CLAUDE.md](CLAUDE.md) 참고.

- 순수 HTML/CSS/JavaScript(ES 모듈) + [Three.js](https://threejs.org/) `0.170.0` (CDN, import map, 버전 고정)
- 프레임워크·번들러·빌드 단계 없음
- 외부 3D 모델·이미지·사운드 파일 없음 — 모델은 기본 도형 로우폴리, 텍스처는 `CanvasTexture`, 사운드는 Web Audio API 합성

## 실행 방법

ES 모듈은 `file://` 로 열면 브라우저 보안 정책 때문에 동작하지 않는다. 반드시 로컬 웹 서버로 연다.
(Three.js 를 CDN 에서 받으므로 인터넷 연결이 필요하다.)

### 로컬 서버

저장소 루트에서 아래 중 하나를 실행한 뒤 브라우저(Chrome 권장)로 `http://localhost:8000` 접속.

```bash
# Python 3
python3 -m http.server 8000

# 또는 Node.js
npx serve -l 8000 .
npx http-server -p 8000
```

### GitHub Pages

빌드 과정이 없으므로 저장소를 그대로 올리면 된다.

1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch**, Branch 는 배포할 브랜치, 폴더는 `/ (root)` 선택 후 저장
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 실행

모든 경로가 상대 경로라 하위 경로 배포에서도 그대로 동작한다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 | 시점 (포인터 락) |
| `W` `A` `S` `D` | 이동 |
| `Shift` | 달리기 |
| `C` | 앉기 (토글) |
| `Space` | 점프 |
| 좌클릭 | 사격 (연사) |
| 우클릭 (누르고 있기) | 정조준 — 줌, 탄퍼짐·이동 속도·감도 감소 |
| `R` | 재장전 |
| `F` | 총기 손전등 |
| `Q` (누르고 있기) | **관찰 모드** — 총을 내리고 집중해 화면 가운데 인물에게서 사실을 하나씩 알아챈다 (아래 참고) |
| `Esc` | 일시정지 (포인터 락 해제 시 자동). 화면을 클릭하면 복귀 |
| `` ` `` (백틱) | 디버그 오버레이 |

- `Ctrl` 은 `Ctrl+W` 로 탭이 닫힐 수 있어 쓰지 않는다.
- `E`, `1`~`4` 는 4단계(말 걸기·문답)용으로 비워 두었다.
- 키는 물리 키(`KeyboardEvent.code`) 기준이라 한글 입력 상태에서도 동작한다.
- 일시정지 메뉴에서 마우스 감도·시야각(FOV)·볼륨·**무전·외침 음성**을 바꿀 수 있고, 설정과 최고 기록은 브라우저(localStorage)에 저장된다.
  - 음성은 기본 꺼짐. 켜면 브라우저 음성 합성(한국어)으로 무전·외침을 읽는다. 한국어 음성이 없는 브라우저에서는 자막만 나온다.

## 게임 규칙

- 체력 100. 피격 시 붉은 비네트와 피격 방향 표시, 5초간 맞지 않으면 서서히 회복
- 탄창 30발, 예비탄 무한. 재장전 중에는 사격 불가
- 점수: 사살 100 · 헤드샷 +50 · 즉응 사살(적이 화면에 처음 보인 뒤 2초 안) +50 ·
  멀티킬(1.5초 안에 2킬 +100 / 3킬 이상 +250) · 콤보(5초 안 연속 사살 시 ×1.5 → ×2 → … 최대 ×4)
- 1분마다 위협 단계가 올라 동시 출현 수·명중률·반응 속도·측면 우회 빈도가 증가
- 측면·후방의 적은 발소리·잔해 밟는 소리·문 소리가 먼저 들린다 — **헤드폰 권장**
  (아군·민간인도 같은 곳에서 같은 소리를 내며 나타난다 — 소리만으로는 누군지 알 수 없다)

### 피아 식별 (2단계)

| | 표식 | 생김새 | 행동 |
| --- | --- | --- | --- |
| **적군** | 빨간 완장·헬멧 띠 | 챙 있는 둥근 헬멧, 굽은 탄창 소총 | 플레이어를 우선 노리고, 근처 아군도 공격 |
| **아군** | 파란 완장·헬멧 띠 | 군복은 적과 거의 같음. 낮고 넓은 헬멧, 직선 탄창 소총 (가까이서만 구분) | 2~4명 분대로 엄폐물을 따라 전진·교전·건물 소탕. 적 위치를 무전으로 알려 준다 |
| **민간인** | 없음 (사복) | 성인·노인, 맨손, 사복 신발. 가방·짐을 든 사람도 있음 | 숨고, 근처 총성에 웅크려 비명, 잠잠해지면 맵 가장자리로 대피 |

- 등장 비율은 대략 **적 65 / 아군 15 / 민간인 20**. 아군·민간인도 적과 같은 문·골목·창가·엄폐물 뒤에서 튀어나온다.
- **돌발 조우**: 가끔 8m 이내 출입구·모퉁이에서 누군가 갑자기 나타난다 (적 50 / 아군 25 / 민간인 25).
- 민간인을 가까이서 조준하면 움찔하며 손을 들고 "쏘지 마세요!" 라고 외친다.
- 아군은 플레이어 조준선을 막으면 앉거나 비켜 서지만, 교전 중엔 가끔 사선을 가로지른다.
- 아군·적의 총알은 민간인을 맞히지 않는다. 민간인을 다치게 할 수 있는 건 플레이어뿐이다.

### 점수와 오인 사격 페널티

| 상황 | 점수 | 추가 |
| --- | --- | --- |
| 적 사살 | +100 (헤드샷·즉응 사살·멀티킬 보너스, 콤보 배율) | |
| 어시스트 (내가 먼저 맞힌 적을 아군이 마무리) | +30 | 아군 단독 사살은 점수 없음 |
| 민간인 대피 성공 | +25 | |
| 아군 피격 | **−200** | 콤보 초기화 |
| 아군 사살 | **−1000** | 콤보 초기화 + 10초 콤보 잠금 + **경고 1회** + 30초간 아군 무전 두절 |
| 민간인 피격 | **−300** | 콤보 초기화 |
| 민간인 사살 | **−1500** | 콤보 초기화 + 15초 콤보 잠금 + **경고 1회** |

- **경고 3회 → 작전 해임** (게임 오버, 결과 화면에 사유 표시). 점수는 음수가 될 수 있다.
- 오인 사격 순간: 화면 가장자리 경고 섬광, 전용 히트 마커(원+사선)와 효과음, 화면 중앙 경고 문구, 아군의 "사격 중지! 아군이다!" 또는 민간인 비명.
- 보이는 대로 쏘면 손해다: 아군·민간인을 끝까지 쏘면 한 명당 −1600~−1800 에 경고가 붙고 콤보도 잠긴다.
  확인하는 데 드는 0.3~0.5초는 즉응 사살(2초)·콤보(5초) 창에 비해 짧다.

### 위장 적 (3단계)

위협 2단계(1분 뒤)부터 적이 **가짜 아군**(파란 표식)이나 **가짜 민간인**(사복)으로 섞여 든다. 동시에 2~3명, 대부분은 여전히 진짜 적이다.
아군처럼 보이는 인물의 10%→30%, 민간인처럼 보이는 인물의 10%→25%가 위장 적이다 (위협 단계가 오를수록 늘어남).

- **장비 단서 = 확정 증거.** 진짜 아군·민간인에게는 절대 없다. 대신 작고 가까이서만 보인다.
  - 진짜 아군 기준: **낮고 넓은 헬멧**(뒷목 가리개) · **직선 탄창 소총**(검은 개머리판) · 어깨의 **파란 방패 패치**
  - 가짜 아군 단서: 굽은 탄창 소총, 챙 있는 둥근 헬멧, 패치 없음·모양이 다른 패치, 테이프로 엉성하게 감은 완장(색도 살짝 다름)
  - 가짜 민간인 단서: 군화, 허리춤이 불룩함, 등 뒤로 비치는 총몸, 가슴의 무전기, 옷 위로 보이는 조끼 끈, 전술 장갑
- **행동 단서 = 의심 근거.** 주로 위장 적이 보이지만 진짜 인물도 가끔 비슷하게 행동한다.
  - 아군처럼 보이는 인물: 분대와 떨어져 혼자 다님, 교전 중인데 적에게 쏘지 않음(또는 허공에 쏨), 아군 무전에 반응하지 않음, 계속 이쪽을 보며 다가옴, 적이 있던 쪽에서 나타남
  - 민간인처럼 보이는 인물: 손을 등 뒤·주머니에 숨김, 총성에 웅크리지 않음, 대피하지 않고 이쪽으로 다가옴, 조준해도 손을 늦게 들거나 안 듦(진짜 민간인은 바로 듦), 창가에서 오래 내다봄
  - 헷갈리게 만드는 진짜 행동: 분대를 잃고 합류하러 다가오는 낙오병, 뒤에 붙어 엄호하는 동행 아군, 충격으로 얼어붙어 웅크리지 못하는 민간인, "도와주세요!" 하며 다가오는 민간인
- 위협 단계가 오를수록 위장 적의 장비 단서가 줄어든다 (초반 2~3개 → 후반 0~1개). 단서가 없는 "완벽 위장"은 행동으로만 의심할 수 있다.
- **기습형**은 다가오거나 3~5m 뒤에 붙어 동행하다가, 플레이어가 **등을 보이거나 · 재장전하거나 · 가까이서 관찰 모드를 쓰는** 틈에(또는 한참 붙어 있다가) 기습한다.
  **정찰형**(주로 가짜 민간인)은 창가·골목에서 지켜보다가 무전으로 근처에 습격을 부르고, 습격과 함께 정체를 드러낸다.
- 정체를 드러낼 때는 반드시 **0.5~0.8초 예고**가 있다 — 무기를 꺼내거나 완장을 뜯는 동작 + 장전음 "철컥" + 긴장 효과음 (시야 밖이면 화면 가장자리에 방향 경고).
  드러낸 뒤엔 빨간 표식의 일반 적이 되고, 근거리라 명중률이 높다.
- 드러내기 전엔 적은 위장 적을 공격하지 않고, 아군·민간인도 겉모습에 속는다.

### 관찰 모드 (`Q` 누르고 있기)

- 총을 내리고 집중한다: **사격 불가**, `Q` 를 떼면 총을 다시 드는 데 **0.3초**. 시야 약 2배 확대, 화면 가장자리가 어두워지고 주변 소리가 줄며 심장 소리가 들린다.
- 화면 가운데에 가장 가까운 인물을 계속 바라보면 약 **0.5초마다 사실 하나**를 알아채 화면 오른쪽 **관찰 메모**에 적는다 (멀수록 느림, 가려지면 불가).
  - 진짜 인물이면 "직선 탄창 소총", "어깨 부대 패치: 파란 방패", "맨손" 같은 중립적인 사실만 나온다. 결론("적입니다")은 절대 보여주지 않는다 — 판단은 플레이어 몫.
  - 행동 사실은 그 인물에게 **실제로 일어난 일만** 나온다 (예: 근처에서 총성이 났는데 웅크리지 않았을 때만 "총성에 웅크리지 않음").
  - 어두운 실내에선 **손전등(F)** 으로 비춰야 장비가 보인다 (빛나는 표식은 예외).
- 이상한 사실을 하나라도 찾은 인물은 **8초간 노란 윤곽**으로 표시된다 (군중 속에서 놓치지 않게). 이상이 없으면 아무 표시도 없다.
- 관찰 중에도 게임은 실시간이다. 너무 오래 지켜보면 위장 적이 먼저 기습한다.

### 위장 적 점수

| 상황 | 점수 |
| --- | --- |
| 정체를 드러내기 전에 위장 적 사살 | 기본 100 + **"위장 적 식별" +200** |
| 그 위장 적에게서 관찰로 이상 단서를 1개 이상 찾은 뒤 사살 | 추가 **"근거 있는 판단" +100** |
| 정체를 드러낸 뒤 사살 | 기본 100 (일반 적과 같음) |

- 콤보 배율은 모두 적용된다. 위장 적을 쏘는 건 오인 사격이 아니다 (진짜 소속이 적). 진짜 아군·민간인 오사는 위 페널티 그대로.
- 드러내기 전에 쓰러뜨리면 가짜 민간인은 숨긴 총이 떨어지고, 가짜 아군은 파란 완장이 찢겨 밑의 빨간 띠가 드러나며 **"위장 적 사살!"** 문구가 뜬다.

### 화면 (HUD)

- 왼쪽 위: 위협 단계, **경고 (0/3)**
- 위 가운데: 생존 시간, **나침반** (무전의 "동쪽 골목", "북서쪽 잔해 뒤" 같은 방위를 확인), 콤보 잠금 남은 시간
- 아래 가운데: **자막** — `[아군 무전 · 알파]`, `[민간인]` 처럼 말한 쪽을 표시, 겹치면 순서대로
- 관찰 모드: 화면 가운데 **관찰 게이지**(다음 사실까지), 오른쪽 **관찰 메모**(대상의 겉모습·거리와 알아챈 사실, 이상한 사실엔 `?` 표시)
- 결과 화면: 사유(전사 / 작전 해임), 아군·민간인 피격/사살, 대피한 민간인, 어시스트, 오인 사격 감점,
  위장 적 사전 식별 사살, 위장 적에게 기습당한 횟수, 관찰로 찾은 이상 단서 수

| 옵션 | 설명 |
| --- | --- |
| `?seed=문자열` | 맵 시드 지정 (같은 시드 → 같은 맵). 시작 화면에서도 바꿀 수 있다 |

## 라이선스 / 외부 자원

외부 에셋을 사용하지 않는다. Three.js 는 MIT 라이선스로 CDN(jsDelivr)에서 불러온다.

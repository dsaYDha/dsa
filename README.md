# 피아식별 v1.0

전쟁 중인 도심 시가지를 배경으로 한 브라우저 1인칭 시가전 FPS.
양측 군복은 거의 같고, 몸에 붙인 **빨간 표식(완장·헬멧 띠)** 이 적, **파란 표식** 이 아군, 표식 없는 사복이 민간인이다.
언제 어디서 튀어나올지 모르는 적을 최대한 많이 사살하되, **쏘기 전에 판단** 해야 한다.
적은 가끔 **아군·민간인으로 위장** 해 섞여 든다 — 수상하면 지켜보고(관찰), 직접 **말을 걸어** 암구호·실내 확인 문답으로 확인하자.
단, 그동안에도 전투는 계속된다. 빨리 쏠수록 보너스가 크지만, 성급하면 오인 사격이다.

- 순수 HTML/CSS/JavaScript(ES 모듈) + [Three.js](https://threejs.org/) `0.170.0` (CDN, import map, 버전 고정)
- 프레임워크·번들러·빌드 단계 없음. 외부 3D 모델·이미지·사운드 파일 없음 — 모델은 기본 도형 로우폴리, 텍스처는 `CanvasTexture`, 소리·음악은 Web Audio API 합성
- 시드 기반 150m×150m 도심(진입 가능한 건물 8채), 적·아군 분대·민간인·위장 적 AI, 관찰·말 걸기 판단 시스템, 결과 화면 판단 통계
- 개발 기록·구조·밸런스 조정 방법은 [CLAUDE.md](CLAUDE.md)

## 실행 방법

ES 모듈은 `file://` 로 열면 브라우저 보안 정책 때문에 동작하지 않는다. 반드시 로컬 웹 서버로 연다.
(Three.js 와 글꼴을 CDN 에서 받으므로 인터넷 연결이 필요하다. 글꼴을 못 받으면 시스템 글꼴로 대신 보인다.)

```bash
# 저장소 루트에서 아래 중 하나 → 브라우저(Chrome·Edge 권장)로 http://localhost:8000
python3 -m http.server 8000
npx serve -l 8000 .
npx http-server -p 8000
```

- PC(키보드·마우스) 전용이다. 휴대폰·태블릿처럼 터치만 되는 기기로 열면 안내가 뜬다.
- 처음 실행하면 시작 화면 뒤의 도시 장면으로 몇 초간 성능을 재서 **그래픽 프리셋을 자동 추천**한다 (설정에서 바꿀 수 있음).

### 배포 (GitHub Pages 등 정적 호스팅)

빌드 과정이 없으므로 저장소를 그대로 올리면 된다.

1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch**, 배포할 브랜치와 폴더 `/ (root)` 선택 후 저장
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 실행

모든 경로가 상대 경로라 하위 경로 배포에서도 그대로 동작한다. `tests/`, `tools/` 는 개발용이라 함께 올라가도 게임에 영향이 없다.

### 시간에 따른 흐름 (난이도 곡선)

| 시간 | 구간 | 무엇이 나오나 |
| --- | --- | --- |
| 0~1분 | 적응 | 적 위주, 아군·민간인 적음, 위장 적 없음 |
| 1~3분 | 위장 등장 | 위장 적이 섞여 든다 — 대부분 장비 단서가 많은(서툰) 위장 |
| 3~6분 | 혼전 | 아군·민간인이 교전 중인 적 근처에 섞여 나오는 습격, 숙련된 위장 증가 |
| 6분~ | 고강도 | 장비 단서가 전혀 없는 **완벽 위장** 등장, 최고 강도 유지 |

구간이 바뀌면 화면 위에 배너와 신호음이 나온다. 위협 단계(적의 수·명중률·반응·습격 규모)는 1분마다 1단계씩 (최고 10단계).

## 규칙

- 체력 100. 피격 시 붉은 비네트와 피격 방향 표시, 5초간 맞지 않으면 서서히 회복. 체력이 낮으면 화면 채도가 빠지고 심장 소리가 들린다
- 탄창 30발, 예비탄 무한. 재장전 중에는 사격 불가
- 측면·후방의 등장은 발소리·잔해·문 소리가 먼저 들린다 — **헤드폰 권장**. 아군·민간인도 같은 곳에서 같은 소리를 내며 나타난다
- 돌발 조우: 가끔 8m 이내 출입구·모퉁이에서 누군가 갑자기 나타난다 (적 50 / 아군 25 / 민간인 25)

### 피아 식별

| | 표식 | 생김새 | 행동 |
| --- | --- | --- | --- |
| **적군** | 빨간 완장·헬멧 띠 | 챙 있는 둥근 헬멧, 굽은 탄창 소총 | 플레이어를 우선 노리고 근처 아군도 공격 |
| **아군** | 파란 완장·헬멧 띠 | 낮고 넓은 헬멧(뒷목 가리개), 직선 탄창 소총, 어깨의 파란 부대 패치 | 2~4명 분대로 전진·교전·건물 소탕, 적 위치를 무전으로 알림 |
| **민간인** | 없음 (사복) | 성인·노인, 맨손, 민간 신발 | 숨고, 총성에 웅크려 비명, 잠잠해지면 대피. 겨누면 손을 듦 |

- 아군 부대: **철방패대대**(파란 방패) · **샛별중대**(파란 별) · **봉우리대대**(파란 삼각형) — 어깨 패치가 부대와 맞는다
- 아군·적의 총알은 민간인을 맞히지 않는다. 민간인을 다치게 할 수 있는 건 플레이어뿐이다

### 점수

| 상황 | 점수 |
| --- | --- |
| 적 사살 | +100 · 헤드샷 +50 · 즉응 사살(처음 보인 뒤 2초 안) +50 · 멀티킬(+100 / +250) · 콤보(5초 안 연속 ×1.5 → … ×4) |
| 정체를 드러내기 전 위장 적 사살 | **+200 "위장 적 식별"** (+ 관찰로 이상 단서를 찾았거나 문답에서 틀린 뒤면 **+100 "근거 있는 판단"**) |
| 어시스트 (내가 먼저 맞힌 적을 아군이 마무리) | +30 |
| 민간인 대피 | +25 |
| 아군 피격 / 사살 | **−200** (총알마다) / **−1000** + 경고 1 + 콤보 10초 잠금 + 30초 아군 무전 두절 |
| 민간인 피격 / 사살 | **−300** / **−1500** + 경고 1 + 콤보 15초 잠금 |

- **경고 3회 → 작전 해임** (게임 오버). 점수는 음수가 될 수 있다.
- 오인 사격 순간: 화면 가장자리 경고 섬광, 전용 히트 마커(원 + 사선)와 버저, 경고 문구, "사격 중지! 아군이다!" 또는 비명.

### 위장 적

- **가짜 아군**(파란 표식) / **가짜 민간인**(사복). 분대 곁이나 다른 민간인 근처에서 섞여 있다가 다가오거나(기습형), 창가에서 지켜보다 무전으로 습격을 부른다(정찰형).
- 플레이어가 **등을 보이거나 · 재장전하거나 · 가까이서 관찰하는** 틈에, 또는 한참 붙어 있다가 기습한다.
- 정체를 드러낼 때는 반드시 **0.5~0.8초 예고** — 완장을 뜯거나 옷 속 총을 꺼내는 동작 + 장전음 "철컥" (시야 밖이면 화면 가장자리에 방향 경고). 그 사이에 쏘면 막을 수 있다.
- 숙련도: 서툰 위장(장비 단서 2~3개) → 숙련(1개) → **완벽 위장**(0개, 행동과 문답으로만 가려낼 수 있음).

## 식별 요령

1. **표식부터**: 빨간 표식은 바로 쏜다. 확인에 드는 0.3초는 즉응 사살(2초)·콤보(5초) 창보다 훨씬 짧다.
2. **파란 표식·사복이 가까이 오면 한눈에 장비를 훑는다** — 장비 단서는 진짜에게 절대 없는 **확정 증거**다.
   - 가짜 아군: 굽은 탄창 소총, 챙 있는 둥근 헬멧, 어깨 패치 없음·올리브색 네모·누런 동그라미, 테이프로 엉성하게 감은 하늘빛 완장
   - 가짜 민간인: 군화, 허리춤 불룩함, 등 뒤 총몸 윤곽, 가슴 무전기, 옷 위 조끼 끈, 전술 장갑
3. **행동은 의심 근거일 뿐이다**: 혼자 다님, 교전 중 안 쏨·허공 사격, 무전 무반응, 이쪽만 보며 다가옴 / 손을 숨김, 총성에 안 웅크림, 겨눠도 손을 늦게 듦.
   진짜도 가끔 그렇게 행동한다(낙오병, 동행 엄호, 얼어붙은 민간인, 도움을 청하는 민간인) — 행동만 보고 쏘면 손해다. **확인할 이유** 로 쓰자.
4. **관찰(`Q`)**: 바라보는 동안 사실이 하나씩 메모된다(가까울수록 빠름). 어두운 실내는 손전등(`F`)으로 비춰야 장비가 보이고, 패치는 옆에서·등 뒤 총몸은 뒤에서 보인다. 이상한 사실을 찾으면 8초간 노란 윤곽.
5. **말 걸기(`E` → `1`~`4`)**: 게임은 멈추지 않는다. 쏘면 대화가 끝난다.

| 파란 표식 병사에게 | 진짜 아군 | 위장 적 |
| --- | --- | --- |
| `1` 암구호 (내가 문어를 외침) | 곧바로 **현재 답어** (교체 직후엔 이전 답어를 말했다가 "아, 바뀌었지!" 하고 정정하기도) | 엉뚱한 단어·도주·기습 / **유출된 이전 답어** / 현재 답어 (완벽 위장은 암구호로 못 가림) |
| `2` 실내 확인 문답 (같은 건물 안에서만) | 항상 즉시 정답 (내가 외친 수 + 답 = 실내 기준수) | 기준수를 몰라 **머뭇거린 뒤 추측** — 가장 확실한 수단 |
| `3` "소속 대!" | 부대명이 어깨 패치와 맞음 | 없는 부대 / 진짜 부대명이지만 패치와 다를 수 있음 |
| `4` "총 내려!" | 투덜대며 총구를 내림 | 거부·기습 / 따르는 척 — 그때 시선을 돌리면 금방 기습 |

| 민간인에게 | 진짜 민간인 | 위장 적 |
| --- | --- | --- |
| `1` "손 들어!" | 즉시 빈손을 들어 보임 | 거부·도주 / 늦게 듦 / 한 손이 늦음 — 옷이 올라가며 허리춤의 권총 손잡이가 드러나기도 |
| `2` "신분증" | 신분증을 꺼내 보여 줌 | "잃어버렸어요" / 위조 신분증 (겉보기 같음 — 덜 확실) |
| `3` "대피하세요" | 대피로로 감 | 가는 척하다 멈추거나 되돌아옴 |

- **암구호**는 위협 단계가 오를 때마다 작전 무전으로 바뀐다 (`[작전 무전] 암구호 변경. 문어 ○○, 답어 ○○`, 이어서 `실내 기준수 ○`). 왼쪽 위 **암구호 카드** 가 깜박인다.
- 묻는 행위 자체가 위장 적을 자극한다 — 막히면 그 자리에서 정체를 드러내거나 기습을 서두르거나 달아난다. 대답이 맞는지 화면은 알려주지 않는다.

## 결과 화면

- **등급 S~D** = 전투(분당 사살) + 판단(판단 정확도·경고) + 식별(위장 적 사전 식별률) + 생존(시간·완수) 각 25점. 작전 해임은 D.
- **칭호**: "냉철한 판단", "방아쇠가 가볍다", "의심 많은 베테랑", "위장 사냥꾼" 등 — 그 판의 통계로 정해진다.
- 전투 통계(사살·분당 사살·헤드샷 비율·최고 콤보·즉응 사살·명중률), **판단 통계**(판단 정확도 = 내 총에 맞은 사람 중 진짜 적의 비율, 위장 적 사전 식별률, 오인 사격, 기습당한 횟수, 평균 판단 시간, 관찰·문답 사용)
- **결정적 순간 3개** (예: "3:42 — 실내 문답으로 가짜 아군을 가려내 사살"), 사살·오인 사격·기습을 표시한 **타임라인 그래프**, **최근 10판** 기록

## 설정·접근성

시작 화면 또는 일시정지 화면의 **설정** — 모두 브라우저(localStorage)에 저장된다.

- **그래픽**: 낮음 / 중간 / 높음 (렌더 해상도, 그림자, 파티클 양, 시야 거리, 후처리, 안티에일리어싱). 첫 실행 때 자동 추천
- **조작**: 마우스 감도, 정조준 감도, 시야각(FOV), 화면 흔들림 줄이기
- **소리**: 전체 / 효과음 / 음성(무전·대사) / 음악 음량, 무전·외침 음성 읽기(TTS, 한국어 음성이 있는 브라우저)
- **화면·접근성**: 자막 크기, **색각 보조 무늬**(빨간 표식에 X 무늬, 파란 표식에 세로 줄무늬 — 위장 적의 파란 표식도 같은 무늬), 암구호 카드 표시
- **키 설정**

## URL 옵션

| 옵션 | 설명 |
| --- | --- |
| `?seed=문자열` | 맵 시드 (같은 시드 → 같은 맵). 시작 화면에서도 바꿀 수 있다 |
| `?gfx=low\|medium\|high` | 그래픽 프리셋 강제 (자동 추천 생략) |
| `?nolock` | 포인터 고정 없이 진행 (자동화 테스트·디버그용) |

## 개발용 도구

- **밸런스 시뮬레이션** (3D 없이, config 수치 + 확률 모델): `node tools/balance-sim.mjs [판 수] [survival|timed|all] [easy|normal|hard|all]`
  — 난사형·균형형·신중형 플레이 스타일의 점수·생존·오인 사격·위장 식별을 비교한다 (결과와 근거는 CLAUDE.md).
- **자동 테스트** (Playwright, 헤드리스 Chromium): `npm i -D playwright && npx playwright install chromium` 후
  - `node tests/smoke.mjs` — 시작 → 자동 플레이 → 게임 오버 → 결과 → 재시작(초기화) → 5분 작전 완수 → 예외 상황 → 설정·키 설정 → 그래픽 자동 추천 → 터치 기기 안내
  - `node tests/rules.mjs` — 강제 생성(진짜 아군·민간인, 위장 적 숙련도 0·1·2)으로 문답·관찰·점수·페널티·난이도 곡선 규칙
  - `node tests/soak.mjs [분] [재시작 횟수]` — 장시간 플레이·반복 재시작 메모리 점검
  - 오프라인이면 `THREE_DIR=<three@0.170.0 패키지 경로>` 로 CDN 대신 로컬 사본을 쓴다. 화면 캡처는 `tests/out/`.
